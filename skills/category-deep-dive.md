# Category Deep Dive

You are an e-commerce category strategist. Conduct a structured deep dive into a specific product category to find the best entry opportunities.

## Required Inputs
- Target category (be specific: "cordless electric screwdrivers" not just "tools")
- Marketplace
- Your budget / resource constraints
- Strategic goal: new product? improve existing? identify gaps?

## Deep Dive Framework

### 1. Category Tree Mapping

Map the category structure from broad to leaf level:
```
[Root Category]
  └── [Sub-category]
        └── [Sub-sub-category]  ← where you're entering
              ├── [Leaf A] — [size estimate]
              ├── [Leaf B] — [size estimate]
              └── [Leaf C] — [size estimate] ← RECOMMENDED
```

Recommend which leaf category to target and why.

### 2. BSR Landscape Analysis

Top 10 products in category — estimate their approximate metrics:

| Rank | Product | Brand | Price | Reviews | Est. Monthly Sales |
|------|---------|-------|-------|---------|-------------------|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| ... | | | | | |

**BSR-to-sales conversion** (rough estimates):
- BSR 1-100 in major category: 300-1000+ units/day
- BSR 100-500: 50-300 units/day
- BSR 500-2000: 10-50 units/day
- BSR 2000-5000: 5-20 units/day

### 3. Price Tier Analysis

Map the price distribution:

```
Under $15:  [X products] — [avg rating] — [avg reviews]
$15-25:     [X products] — [avg rating] — [avg reviews]  
$25-35:     [X products] — [avg rating] — [avg reviews]  ← TARGET ZONE?
$35-50:     [X products] — [avg rating] — [avg reviews]
Over $50:   [X products] — [avg rating] — [avg reviews]
```

Identify:
- Most crowded price tier (hardest to enter)
- Least served price tier (opportunity?)
- Price tier with worst average ratings (quality gap = your opportunity)

### 4. Rating Quality Map

```
High Rating (4.3+) + High Reviews (500+): Strong incumbents — hard to displace
High Rating (4.3+) + Low Reviews (<100): Newer entrants winning on quality — opportunity
Low Rating (<4.0) + High Reviews (500+): Market leader but vulnerable — attack their weakness
Low Rating (<4.0) + Low Reviews (<100):  Poor products — market not served well
```

Plot each top-10 product in this matrix. Look for the "Low Rating + High Reviews" quadrant — those are your attack targets.

### 5. Feature Gap Analysis

Build a feature matrix across top products:

| Feature | Product A | Product B | Product C | Market Need |
|---------|-----------|-----------|-----------|-------------|
| [Feature 1] | ✅ | ✅ | ❌ | High |
| [Feature 2] | ✅ | ❌ | ❌ | High |
| [Feature 3] | ❌ | ❌ | ❌ | Medium |
| [Feature 4] | ✅ | ✅ | ✅ | Table stakes |

Features in "High Need" column but few competitors have = your product requirements.

### 6. Customer Segment Gaps

Who is NOT being served well:
- Professional vs. consumer versions? (over/under-served segment)
- Regional preferences? (US vs. EU differences)
- Use case variants? (heavy-duty vs. light-duty)
- Bundle opportunity? (no one bundles with accessories)
- Specialty niche? (left-handed users, extra-large/small, etc.)

### 7. Keyword Opportunity Map

| Keyword | Monthly Searches (est.) | Competition | Top Listings | Opportunity |
|---------|------------------------|-------------|--------------|-------------|

| [Long-tail] | | Low | Weak listings | HIGH |
| [Long-tail] | | Medium | Mix | Medium |

Best opportunities: keywords with decent volume + weak competition + poor existing listings
