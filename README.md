**10 professional-grade Claude Code skills for e-commerce product managers and operators.**

Stop writing the same analysis prompts from scratch. This toolkit gives you battle-tested AI workflows built for the full product lifecycle — from market research to launch to optimization.

## Quick Start (5 minutes)

### 1. Install Claude Code
```bash
npm install -g @anthropic-ai/claude-code
```

### 2. Copy Skills to Your Claude Config
```bash
# Create skills directory (if it doesn't exist)
mkdir -p ~/.claude/skills

# Copy all toolkit skills
cp skills/*.md ~/.claude/skills/
```

### 3. Start Using
Launch Claude Code in any project directory and try:

```
Use the market-analysis skill to analyze the portable air compressor category on Amazon US
```

```
Use the listing-optimizer skill to optimize this listing: [paste your listing]
```

```
Use the review-analyst skill to analyze these reviews: [paste reviews]
```

## Real Examples

### Example 1: New Product Research
```
Use the market-analysis skill on cordless electric screwdrivers, Amazon US, $20-45 price range
```
→ Get: market size estimate, top competitors, opportunity score, recommended entry strategy

### Example 2: Improve a Struggling Listing
```
Use the listing-optimizer skill. Marketplace: Amazon US.
Current title: "Power Drill Cordless 20V Battery"
My differentiators: lightweight (3.2 lbs), 2-year warranty, comes with 50-piece bit set
Target keywords: cordless drill set, lightweight drill, home drill kit
```
→ Get: optimized title, 5 bullets, backend keywords, image brief — ready to upload

### Example 3: Pre-Launch Supplier Evaluation
```
Use the supplier-sourcing skill in Mode 2 (Evaluation) for this supplier response: [paste email]
```
→ Get: scored evaluation, red flags identified, pass/caution/reject verdict

### Example 4: Weekly PPC Optimization
```
Use the ppc-optimizer skill in Mode 3 (Weekly Optimization). Here's my search term report data: [paste data]
```
→ Get: keywords to harvest, negatives to add, bids to adjust, weekly summary
